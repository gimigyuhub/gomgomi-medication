# 곰곰이 표정 규칙 (`src/mood.js`)

| 단계 | 입력 → 출력 |
|---|---|
| 시간대 상태 | 약 목록·오늘 체크 기록·현재 시각 → 시간대마다 `곧`(기준 30분 전까지) / `지금`(기준 −30분~+90분) / `늦음`(+90분~4시간) / `놓침`(4시간 초과) / `다 먹음` |
| 최근 기록 | 어제부터 7일 → 복용률, 어제 놓침 여부, 하루 체크가 하나도 없던 연속 일수(그날 이미 등록된 약만 셈) |
| 표정 | 아래 표에서 위에서부터 처음 맞는 단계 |

시간대 기준 시각: 아침 식전 7:30 · 아침 8:00 · 아침 식후 8:30 · 점심 식전 12:00 · 점심 12:30 · 점심 식후 13:00 · 저녁 식전 18:00 · 저녁 18:30 · 저녁 식후 19:00 · 취침 전 22:00 · 기타(시각 없음, 놓침으로 보지 않음)

| 표정 | 조건 |
|---|---|
| 졸림 | 등록한 약이 없음 |
| 뿌듯 | 오늘 예정된 약을 모두 체크 |
| 삐짐 | 오늘 2개 시간대 이상 놓침, 또는 이틀 넘게 체크가 전혀 없고 오늘도 없음 |
| 울음 | 오늘 1개 시간대 놓침, 또는 최근 7일 복용률 50% 미만이고 오늘 체크 없음 |
| 걱정 | 늦은 시간대가 있음 |
| 재촉 | 지금 먹을 시간대가 있음 |
| 걱정(약하게) | 어제 놓친 약이 있음, 또는 최근 7일 복용률 80% 미만 |
| 기쁨 / 평온 | 문제없음 (3일 연속 다 챙겼으면 기쁨) |

놓친 경우에는 "놓친 약을 두 배로 먹지 말고 약사에게 물어보라"는 안내를 함께 보여 줍니다. 규칙 테스트: `npm test`
