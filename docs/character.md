# 곰곰이 캐릭터 (`src/bear.js`)

SVG 한 장으로 그린 2D 리깅 캐릭터입니다. 몸은 뼈대와 물리로, 얼굴은 버츄얼 유튜버(Live2D)식 파라미터로 움직입니다.

```js
const bear = createBear(element, {mood: 'calm', rank: 0, interactive: true});
bear.setMood('happy', 1);   // 기분(8단계)과 성장 단계(새싹 → 꽃 → 별 → 왕관)
bear.play('cheer');         // 몸 동작
bear.express('wink', 1.2);  // 짧은 표정(초)
bear.say('같이 약 챙겨요!'); // 말풍선 + 입 모양
```

| 종류 | 목록 |
|---|---|
| 기분 | 졸림 · 평온 · 기쁨 · 뿌듯 · 기다림 · 걱정 · 울음 · 삐짐 ([규칙](mood-rules.md)) |
| 몸 동작 | hop · cheer · tap · stomp · pet · hug · belly · spin · yawn · startle · wave · dizzy · land |
| 짧은 표정 | laugh · wink · surprised · shy · love(하트 눈) · dizzy(소용돌이 눈) · yawn · pout · relieved |

## 뼈대

```
root ─ hip ─ spine1 ─ spine2 ─ neck ─ head ─ earL, earR (+ 머리 안 face, muzzle)
  │                     └ armL, armR
  └ legL, legR
```

- 부모 뼈가 돌면 자식 뼈가 관절째 따라 돕니다(FK). 뼈는 늘어나지 않고, 말랑한 귀만 귀 끝 방향으로 최대 1.7배 늘어납니다.
- 몸통은 그룹이 아니라 피부입니다. 윤곽점마다 hip·spine1·spine2 가중치가 있어(선형 블렌드 스키닝) 허리를 꺾으면 몸통이 이어진 채 휩니다.

## 물리

| 항목 | 값 |
|---|---|
| 몸 전체 | 강체(몸무게 4, 중력 2000px/s², 바닥 마찰 1.2, 회전 관성) |
| 부위별 질량비 | 머리 8.1% · 가슴 21.6% · 배 13.9% · 골반 14.2% · 팔 5.0% · 다리 16.1% (Winter, Dempster 자료) |
| 관절 | 매달린 질량에 걸리는 중력·관성력 + 근육 스프링(몸통은 단단하게, 팔은 힘을 빼고) + 자식 관절 반작용 |
| 귀 | 고개를 돌리거나 뛰면 출렁이는 스프링 |

## 만지기

| 동작 | 반응 |
|---|---|
| 머리·귀·배·발·팔 톡 | 부위와 기분에 따라 다른 동작·표정·말 |
| 머리 위에서 옆으로 문지르기 | 쓰다듬기(포인터가 머리 위에 있을 때만) |
| 길게 누르기 · 두 번 톡 · 빠르게 5번 | 안기 · 빙글 · 어지러움 |
| 잡아끌기 | 관절이 먼저 손가락을 따라가고(CCD IK, 관절마다 각도 제한), 닿지 않는 거리만 용수철 힘으로 몸에 전해짐. 멀수록 세고 최대 힘(몸무게의 1.4배)에서 멈춤 |
| 위로 당기기 | 힘이 몸무게보다 크면 떠올라 잡은 점 아래로 매달림. 놓으면 떨어져 착지하고 다시 일어섬 |

팔을 잡고 움직이면 팔만 어깨에서 돕니다. 귀로는 몸을 들 수 없습니다. 한동안 만지지 않으면 혼자 손 흔들기·하품·윙크를 합니다.

## 얼굴 파라미터

표정을 그림으로 바꿔 끼우지 않고, 아래 값으로 매 프레임 눈·눈썹·입을 새로 그립니다. 기분이 바뀌면 값이 목표값으로 부드럽게 옮겨갑니다.

| 파라미터 | 범위 |
|---|---|
| `angleX` / `angleY` | 고개 좌우·상하 (-1~1). 주둥이 10px > 눈 7px > 귀 -4px로 깊이에 따라 다르게 움직임(2.5D) |
| `eyeOpenL` / `eyeOpenR` | 눈 뜸 0~1.2 (깜빡임·윙크) |
| `eyeSmile` | -1 질끈(∪) ~ +1 눈웃음(∩) |
| `eyeBallX` / `eyeBallY` | 시선. 흰자 안에서 눈동자가 움직이고, 터치·마우스 쪽을 봄 |
| `browY` / `browAngle` / `browAlpha` | 눈썹 높이 · -1 걱정 ~ +1 화남 · 보이는 정도 |
| `mouthOpen` / `mouthForm` | 0~1 · -1 시무룩 ~ +1 웃음 (말할 때 립싱크) |

'동작 줄이기' 설정이면 움직이지 않고 기분에 맞는 표정만 보여 줍니다. 물리·관절 값은 `src/bear.js` 위쪽 상수(`BODY_MASS`, `GRAVITY`, `FRICTION`, `FMAX`, `SEG`, `KAPPA`, `ZETA`, `IK_LIMIT`)에서 조정합니다.
